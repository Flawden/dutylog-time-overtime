# Изменения в доработанной версии

## Исправлено
- Автосохранение заметок больше не зависит от текущего `state.days`: сохраняется снимок текста и смены на момент ввода.
- Перед переключением месяца ожидающее сохранение заметки принудительно отправляется на сервер.
- `builtin` теперь работает по смыслу: базовые смены нельзя удалить через UI и API.

## Изменено по уточнённому ТЗ
- «Выходной» снова добавлен в стартовый набор как встроенная смена с 0 часами.
- «5 часов», «12 часов», «Сутки», «Отпуск», «Больничный» и прочее остаются кастомными сменами пользователя.
- В README добавлена продуктовая задумка: заметки в дне, будущие уведомления, Telegram-бот, «будильник», переработки и отгулы.

## Добавлено
- Стартовый набор смен теперь состоит из трёх базовых вариантов: «Дневная», «Ночная», «Выходной».
- Остальные варианты смен предполагаются кастомными для каждого пользователя: название, цвет и часы задаются вручную.
- Добавлено массовое заполнение графика от выбранной даты через `/api/days/fill`.
- Добавлены готовые шаблоны: 2/2, день/ночь/48, пятидневка 5/2, день/72, ночь/72.
- При массовом заполнении заметки в днях не стираются.
- Валидация DTO через `spring-boot-starter-validation`.
- Единый обработчик ошибок API `ApiExceptionHandler`.
- Понятные JSON-ошибки для фронтенда.
- Базовая PWA-подготовка: `manifest.json`, `service-worker.js`, иконки 192/512.
- `application-prod.properties`: отключает H2-console для первого публичного запуска.

## Проверено в этой среде
- Синтаксис JS из `index.html` и `login.html` проверен через `node --check`.
- `service-worker.js` проверен через `node --check`.
- `manifest.json` проверен через `python -m json.tool`.

## Не проверено в этой среде
- Maven-сборка, потому что в контейнере нет команды `mvn` и нет доступа к Maven Central.
