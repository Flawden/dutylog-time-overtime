Можно ввести полный интервал датами или коротко: дата начисления + 17:00–20:00. Если вводишь только переработку — план оставь 0; если всю фактическую смену — вычти план.

Смены
Типы смен и их время
Здесь создаются кастомные смены и настраиваются встроенные: начало, конец, обед, плановые часы и уведомления.
Время смены пригодится для подсказок, будущих уведомлений и кнопки «план по смене».
Быстрые сценарии
Шаблоны для переработок
Сценарии создаются здесь, а применяются в панели выбранного дня. Они только заполняют поля переработки — начисление всё равно подтверждаешь отдельно.
свои сценарии
Сценарии сохраняются в профиле. Их можно удалить кнопкой × на карточке.
