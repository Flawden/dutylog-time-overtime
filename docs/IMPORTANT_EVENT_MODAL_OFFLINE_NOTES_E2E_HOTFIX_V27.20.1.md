# v27.20.1 — Important Event Modal & Offline Notes E2E Hotfix

## Причина

Полный Chromium gate v27.20.0 прошёл 26 из 29 сценариев и обнаружил три независимых расхождения:

1. details-modal важного события оставался поверх интерфейса после редактирования и перехватывал навигацию;
2. `selectDate()` требовал видимую ячейку месячной сетки даже в режиме Day;
3. старый PWA-тест ожидал `readonly`, хотя продуктовый контракт v27.20.0 разрешает оффлайн-редактирование существующих заметок.

## Исправление жизненного цикла событий

- введён единый `closeImportantEventModals()`;
- открытие details сначала закрывает editor, открытие editor сначала закрывает details;
- успешное сохранение закрывает оба окна до и после обновления данных;
- интерактивные действия карточки используют `preventDefault()` и `stopPropagation()`;
- row-click игнорирует кнопки, ссылки, поля формы и элементы с button-role.

Контракт: одновременно может быть открыт только один event-modal, а после save оба скрыты.

## Mode-aware `selectDate()`

Helper теперь:

- возвращается сразу, когда нужная дата уже выбрана и панель дня видима;
- при необходимости временно переключается в Month;
- выбирает дату;
- восстанавливает исходный Week/Day mode.

Это сохраняет идемпотентность и не связывает тесты с видимостью скрытой месячной сетки.

## Оффлайн-заметки

PWA-сценарий теперь проверяет настоящий пользовательский путь:

1. существующая заметка создаётся онлайн;
2. shell открывается из IndexedDB без сети;
3. редактор остаётся доступным, создание новой заметки заблокировано;
4. изменение попадает в snapshot и единственную `updateNote`-операцию;
5. offline reload сохраняет текст и очередь;
6. reconnect отправляет PATCH;
7. очередь очищается;
8. online reload получает серверно сохранённый текст.
